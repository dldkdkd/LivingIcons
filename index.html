What LivingIcons includes

Animated icons

GIF and APNG playback directly on your Home Screen, plus static PNG and JPG overrides.

Per-app controls

Choose artwork, change speed and looping, and preview each app inside the native Settings pane.

Theme Studio

Build, organize, edit, and switch complete animation packs without replacing original app icons.

Badge-safe rendering

Notification badges remain visible above animated artwork and continue updating normally.

Install and set up

1. Add https://dldkdkd.github.io/LivingIcons/ to Sileo.

2. Install LivingIcons. Sileo will also install Legacy arm64e Support (oldabi) when required.

3. Respring, then open Settings → LivingIcons.

4. Select Installed Apps to assign artwork, or open Themes to activate a full pack.

5. Custom themes live at /var/jb/var/mobile/Documents/LivingIcons/Themes/.
