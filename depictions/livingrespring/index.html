LivingRespring

Use a custom GIF as the iOS respring animation.

FreeAdam Never Lack

Features

  • Choose a GIF from Settings
  • Automatically optimizes GIFs into safe PNG frames
  • Preview the processed animation before respringing
  • Playback speed and Fit / Fill / Center controls
  • Falls back to the stock animation if custom assets cannot load

Compatibility

iOS 17. Rootless build; RootHide users can use a compatible converted/native build where supported.
